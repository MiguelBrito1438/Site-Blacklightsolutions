# BlackLight Solutions

Landing page institucional da BlackLight Solutions, empresa especializada em infraestrutura de redes, conectividade wireless e cabeamento estruturado.

**Site publicado:** [blacklighsolutions.vercel.app](https://blacklighsolutions.vercel.app)

## Sobre o projeto

Site estático de página única, desenvolvido com HTML, CSS e JavaScript. A experiência apresenta a empresa, suas soluções, setores atendidos, diferenciais e canais de contato.

### Recursos

- Layout responsivo para desktop e dispositivos móveis.
- Navegação por seções e menu adaptado para telas pequenas.
- Animações e interações com respeito à preferência por movimento reduzido.
- Ações de contato pelo WhatsApp e Instagram.
- Logos da marca e favicon circular com fundo transparente fora do ícone.

## Executar localmente

Não é necessário instalar dependências ou compilar o projeto. Na pasta do site, inicie um servidor local:

```bash
python -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000).

Também é possível abrir `index.html` diretamente no navegador, embora um servidor local represente melhor o ambiente publicado.

## Publicação

O projeto é estático e pode ser publicado diretamente na Vercel, sem comando de build e com a raiz do projeto apontando para esta pasta. O endereço de produção atual é [blacklighsolutions.vercel.app](https://blacklighsolutions.vercel.app).
